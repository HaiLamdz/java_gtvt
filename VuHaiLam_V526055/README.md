## Danh sách bài tập

### 📌 Bài 1: Tính tổng mảng `n` phần tử (`Bai1.java`)
- **Đề bài**: Viết chương trình nhập vào `n` phần tử `int` của 1 mảng (`n` nhập từ bàn phím). Tính và in ra tổng.

### 📌 Bài 2: Mảng tổng của 2 mảng (`Bai2.java`)
- **Đề bài**: Viết hàm nhận vào 2 mảng và in ra mảng tổng (mỗi phần tử là tổng của 2 phần tử thuộc mảng đầu vào, có số phần tử bằng mảng nhiều phần tử hơn).

### 📌 Bài 3: Nhập mảng từ chuỗi duy nhất (`Bai3.java`)
- **Đề bài**: Viết chương trình cho phép người dùng nhập vào 1 mảng các số nguyên bằng 1 chuỗi duy nhất với các phần tử cách nhau bởi dấu cách `" "`. In ra số phần tử và tổng các phần tử.
  - *Ví dụ*: Người dùng nhập `"3 4 5 33 554 67 23 6 8 5"`
  - *In ra*: `Số phần tử: 10; Tổng: 708`

### 📌 Menu chạy thử (`Main.java`)
- Cho phép chọn nhanh bài 1, bài 2 hoặc bài 3 để chạy thử trực tiếp từ console.

## Cách biên dịch và chạy

Từ thư mục gốc dự án (`d:\java_gtvt`):

```bash
# Biên dịch
javac -encoding UTF-8 VuHaiLam_V526055/*.java

# Chạy Menu
java VuHaiLam_V526055.Main

# Hoặc chạy từng bài
java VuHaiLam_V526055.Bai1
java VuHaiLam_V526055.Bai2
java VuHaiLam_V526055.Bai3
```
